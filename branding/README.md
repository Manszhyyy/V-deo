## Пометка «ИИ»

- **TikTok:** при загрузке включи «Контент, созданный ИИ» («AI-generated content»). Видео без пометки TikTok может скрыть или удалить, а с пометкой охваты не режет.
- **YouTube:** для мультиков галочку «изменённый или синтетический контент» ставить не обязательно. Она нужна, если видео выглядит как реальная съёмка.

## План выкладки

1. **Время:** каждый день в 18:00–20:00 по Казахстану. Хоррор лучше ближе к ночи.
2. **Порядок:** одна серия в день. Следующую выкладывай, когда под прошлой набрались ответы А/Б.
3. **Чередуй жанры:** например, день «Путь наверх», день страшилка. Так на канал подписываются люди с разными интересами, и у каждого всегда есть продолжение.
4. **Название Shorts:** самая цепляющая фраза, потом название сериала и номер. Например: «Скаут из толпы смотрит только на меня 👀 | Путь наверх 1».
5. **Хештеги:** 3–5 штук.
   - Всегда: `#нейровыбор #ии #shorts`
   - Плюс по жанру: `#хоррор #страшилки` / `#ufc #мма` / `#мистика`
